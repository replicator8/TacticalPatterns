Данный проект реализует управление заявками для перевозок, используя паттерны Active Record, Transaction Script, Domain Model, Factory, и Repository. Реализация охватывает ключевые аспекты работы с водителем, сменами и управлением заявок. Код включает примеры создания объектов, управления транзакциями и проверки доступности.
